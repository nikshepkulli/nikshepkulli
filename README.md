### What I've shipped

- **Production RAG assistant (Starteryou)**: an AI career assistant grounded in job and employer content, used across a platform of **15,000+ users and 342 employer partners**. Node.js/Express, Hugging Face LLMs, vector retrieval. I owned retrieval design, prompting and deployment.
- **AI-first engineering org**: as Co-Founder & CTO I built the whole stack (web, iOS, Android, RAG chatbot, cloud) with Claude Code agents as the core workflow: delegating build, infra, debugging and review tasks, then reviewing and shipping to production. Led a 12-person team.
- **FDE function from scratch (Organic Mandya)**: built a 5-person Forward Deployed Engineering team linking engineering with farmer co-ops and retail partners; rebuilt a broken order-routing script and recovered **~₹80k/month** in revenue.
- **Healthcare integrations (Cerner / Oracle Health)**: Spring Boot microservices in a regulated environment, secured with OAuth2/JWT, deployed on Azure.
- **Medical device software**: C/C++ REST control API for a kidney-dialysis reprocessing unit.
